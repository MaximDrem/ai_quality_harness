# presentation-clone Delta

## ADDED Requirements

### Requirement: Кейсы клонирования на шаблоне «Северный ветер»

Сценарий клонирования презентации SHALL включать кейсы `US01-01-07` и `US01-01-08` с приложенным шаблоном «Северный ветер», индивидуальными проверками задания и специфичными для этого шаблона запрещёнными следами.

#### Scenario: Доступны кейсы на шаблоне «Северный ветер»

- **WHEN** загружаются кейсы `US01-01-07` и `US01-01-08`
- **THEN** оба используют приложенный шаблон «Северный ветер»
- **AND** объявляют промежуточный `STYLE.md` и финальный PPTX

#### Scenario: Вводная презентация по ИИ-инструментам

- **WHEN** оценивается финал кейса `US01-01-07`
- **THEN** проверяются 8 слайдов, заданные структура, заголовки, тезисы, инструменты, правила безопасности, шаги доступа, FAQ и призыв
- **AND** отдельно отклоняются следы пользовательского плана и placeholders шаблона

#### Scenario: Памятка новичка

- **WHEN** оценивается финал кейса `US01-01-08`
- **THEN** проверяются 6 слайдов и раскрытие первого рабочего дня, работы с наставником, обучения и обращения за помощью
- **AND** текст должен быть понятной памяткой для новичка без эмодзи

#### Scenario: Памятка содержит только изображения шаблона

- **WHEN** финал кейса `US01-01-08` содержит медиафайлы
- **THEN** существующая функциональная проверка происхождения медиа принимает только файлы, содержимое которых присутствует в шаблоне
- **AND** любой посторонний медиафайл отклоняется

#### Scenario: Финал содержит демонстрационные данные шаблона

- **WHEN** слайды, заметки, метаданные или ссылки кейса `US01-01-07` либо `US01-01-08` содержат специфичные для «Северного ветра» placeholders, выдуманные показатели, контакты или служебные инструкции
- **THEN** соответствующая проверка чистоты завершается ошибкой
- **AND** перечисляет найденные совпадения
